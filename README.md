# tally

Körner zählen und Tausendkorngewicht (TKG) bestimmen – per Handyfoto: Körner fotografieren, automatisch zählen lassen, Probe wiegen, TKG ablesen.

**App öffnen:** https://mjk912.github.io/tally/

Läuft komplett im Browser, ohne Installation und ohne Anmeldung. Auf dem Handy über „Zum Startbildschirm hinzufügen“ wie eine App ablegen.

## So geht's

1. **Körner verteilen** – eine Probe einlagig auf einen glatten, einfarbigen Untergrund legen, möglichst ohne Berührung.
2. **Foto machen** – gleichmäßiges Licht, Handy gerade von oben, nur die Probe im Bild.
3. **Zählen** – tally stellt Empfindlichkeit und Trennen selbst ein. Bei Bedarf nachjustieren, einzelne Körner über den Stift setzen oder löschen oder einen Zählbereich festlegen.
4. **Sortieren** – für das TKG von gereinigtem Saatgut die markierten Kleinkörner aus der Probe nehmen und „Ohne Kleinkorn“ wählen. Hell/Dunkel oder eigene Farben sind optional.
5. **Wiegen** – genau die gezählten Körner wiegen und das Gewicht eintragen.
6. **Speichern und teilen** – Proben je Charge speichern; mehrere Proben werden gemittelt. Aus dem Ø TKG die Saatmenge (kg/ha) berechnen. Ergebnis- und Saatmengen-Bild lassen sich über das Teilen-Menü des Handys sichern oder weitergeben.

## Wichtig

- **Experimentell. Nutzung auf eigene Gefahr, ohne Gewähr.** Die Zählung erfolgt per Bildanalyse; aneinanderliegende Körner werden geschätzt. Ergebnisse bitte stichprobenhaft von Hand prüfen.
- **Gespeichert wird nur im Browser des jeweiligen Geräts.** Beim Löschen der Browserdaten sind gespeicherte Proben weg. Wichtige Ergebnisse über „Teilen“ als Bild sichern.

## Datenschutz

- Fotos werden ausschließlich auf dem eigenen Gerät verarbeitet und nicht hochgeladen.
- Gespeicherte Proben liegen nur im Speicher des Browsers (IndexedDB) auf diesem Gerät.
- Keine Cookies, kein Tracking, keine Analyse-Dienste, keine externen Schriften oder Skripte.
